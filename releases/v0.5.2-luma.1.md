# LumaDrop Optical 0.5.2-luma.1

The first Android wrapper around Decimen Optical Transfer 0.5.2. It bundles the web sender, receiver, decoder worker, WebAssembly codec, and translations for offline use, adds native camera/file integration and received-file saving, and introduces the dark neon LumaDrop presentation.

Known issue: packaged Send and Receive links can open an `ERR_INVALID_RESPONSE` page. This is fixed in `luma.2`.

Archived debug-signed development build; prefer `luma.9`. See the repository changelog for the historical-source note.
