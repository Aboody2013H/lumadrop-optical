# LumaDrop Optical 0.5.2-luma.1

The first Decimen-based Android build. It bundled the whole web sender and receiver into an offline app, connected Android's camera and file picker, added native saving, and introduced the first dark LumaDrop look.

It was a solid start, but the Send and Receive links could still land on an `ERR_INVALID_RESPONSE` page. `luma.2` fixed that.

This is an old debug build kept for the timeline. Use `luma.9` unless you specifically want to try the first wrapper.
