# LumaDrop Optical 0.5.2-luma.10

This release finishes the app's LumaDrop identity. The header, page titles, PWA name, language strings, footer, GitHub links, Releases link, license link, and issue-reporting link now all point to LumaDrop and its own repository.

The footer now credits **© 2026 Aboody Habash (Aboody2013H)**.

The transfer engine remains compatible with the existing Decimen optical protocol. Its original legal notices and upstream credit are still included, as required by the AGPL license.

The APK is release-signed and works on Android 6.0/API 23 or newer. If an older debug build is installed, Android will require it to be removed before this release-signed APK can be installed because the signatures differ.
