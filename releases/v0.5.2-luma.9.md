# LumaDrop Optical 0.5.2-luma.9

This is the build most people should download.

It has everything from the earlier versions: offline file and text transfer, multi-file ZIPs, Android Share support, automatic sending brightness, front/rear camera switching, 1x–10x zoom, native saving, and the final neon LumaDrop icon.

The APK is release-signed and works on Android 6.0/API 23 or newer. If you already installed one of the old debug builds, Android may ask you to uninstall it first because this version uses a different signing certificate.
