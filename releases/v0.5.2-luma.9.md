# LumaDrop Optical 0.5.2-luma.9

The first public LumaDrop release turns the modified Decimen web application into a fully offline, sideloadable Android app.

## What's included

- Animated fountain-coded QR file and text transfer without networking or pairing.
- Multi-file transfer through automatic ZIP packaging.
- Android Share-sheet integration for one or several files.
- Rear/front camera switching and 1x–10x pinch, wheel, and slider zoom.
- Automatic maximum sender brightness with safe restoration afterward.
- Native Android saving for reconstructed files.
- New LumaDrop launcher and PWA icon.
- Dark neon mobile interface and offline app routing fixes.

## Installation

Download `LumaDrop-Optical-v0.5.2-luma9-debug.apk` below and allow installation from your browser or file manager when Android asks. This build is debug-signed for sideloading and requires Android 6.0/API 23 or newer.
