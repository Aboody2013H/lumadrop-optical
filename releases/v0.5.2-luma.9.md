# LumaDrop Optical 0.5.2-luma.9

The current recommended LumaDrop build.

It adds the neon QR-to-camera aperture launcher icon and matching Android/web/PWA artwork on top of `luma.8`, which introduced multi-file ZIP transfer, Android Share integration, automatic transmission brightness, rear/front camera switching, 1x–10x zoom, native saving, offline routing, and arbitrary file transfer.

Download the release-signed APK below. Android 6.0/API 23 or newer is required.

If a debug-signed LumaDrop build is already installed, Android may require it to be uninstalled first because this normal release uses a dedicated production signing certificate.
