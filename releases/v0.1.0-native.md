# LumaDrop Native 0.1.0

The original Kotlin/Jetpack Compose proof of concept, preserved for development history. It uses a separate package (`io.lumadrop.app`) and protocol from the later Decimen-based wrapper.

Highlights: native Storage Access Framework file handling, CameraX plus bundled ML Kit scanning, systematic and fountain-style repair frames, per-frame CRC-32 checks, final SHA-256 verification, and dropped-frame tolerance.

This is an archived debug-signed development build. Prefer `0.5.2-luma.9` for normal use. See the repository changelog for the historical-source note.
