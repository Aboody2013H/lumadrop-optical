# LumaDrop Native 0.1.0

This was the first attempt: a fully native Kotlin/Jetpack Compose prototype. It proved that the basic idea worked before the project moved over to Decimen's faster optical engine.

It has Android file picking and saving, CameraX with the bundled ML Kit scanner, fountain-style repair frames, CRC-32 checks, final SHA-256 verification, and tolerance for missed frames.

This build uses its own package and protocol, so it is separate from the later LumaDrop Optical builds. It's here for the history; most people should download `luma.9` instead.
